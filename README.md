# 나의 가계부 📱

핸드폰 홈 화면에 설치해서 앱처럼 쓸 수 있는 나만의 가계부(PWA)입니다.
서버 없이 동작하며, 모든 데이터는 내 기기(브라우저 localStorage)에만 저장됩니다.

## 주요 기능

- 수입 · 지출 기록, 분류(카테고리) 관리, 월별 예산
- 신용카드 사용액 · 청구 예정 · 카드대금 결제 관리 (소비 관점 / 통장 관점)
- 매달 고정지출 관리, 지출 분석 도넛 차트, 카드별 월별 추이
- JSON 백업 / 복원, CSV 내보내기
- **오프라인 지원** — 한 번 열고 나면 인터넷 없이도 동작
- **홈 화면 설치** — 폰에서 진짜 앱처럼 아이콘으로 실행

## 핸드폰에 앱으로 설치하기

먼저 아래 "배포하기"대로 GitHub Pages 주소를 만든 뒤, 폰 브라우저로 그 주소에 접속하세요.

- **Android (Chrome)**: 설정(⚙) 메뉴의 "홈 화면에 앱 설치" 버튼을 누르거나, 브라우저 메뉴(⋮) → **앱 설치**
- **iPhone (Safari)**: 공유 버튼(□↑) → **홈 화면에 추가**

설치하면 주소창 없는 전체 화면 앱으로 실행되고, 오프라인에서도 열립니다.

## 배포하기 (GitHub Pages)

1. 이 저장소의 **Settings → Pages** 로 이동
2. Source를 **Deploy from a branch**, Branch를 `main` / `/ (root)` 로 설정하고 저장
3. 잠시 후 `https://<계정명>.github.io/my_money/` 주소로 접속 가능

> 데이터는 기기·브라우저별로 따로 저장되므로, 기기를 바꿀 때는
> 설정 → **백업 파일 저장**으로 내려받은 .json을 새 기기에서 **백업 파일 불러오기**로 복원하세요.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 앱 본체 (화면 + 로직 전체) |
| `manifest.webmanifest` | 앱 이름 · 아이콘 · 설치 정보 (PWA 매니페스트) |
| `sw.js` | 서비스 워커 — 오프라인 캐시 |
| `icons/` | 홈 화면 · 앱 아이콘 |
