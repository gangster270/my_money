# 회의실 예약 시스템 🗓

QR을 찍으면 바로 열리고, **월별 달력에서 날짜를 고르고 → 회의실·시간을 골라 예약**하는
사내 공용 회의실 예약 앱입니다. 앱스토어 설치도, 로그인도, 서버 운영도 필요 없습니다.

```
회의실 문 앞 QR  ──스캔──▶  달력 화면  ──날짜 터치──▶  시간표  ──빈칸 터치──▶  예약 완료
```

## 무엇을 할 수 있나요

| 기능 | 설명 |
|---|---|
| **월별 달력** | 한 달 전체를 한눈에. 날짜마다 «누가(부서) 몇 시에» 쓰는지 색 칩으로 표시 |
| **일별 시간표** | 회의실별 세로 타임라인. 빈 시간을 누르면 그 시간으로 바로 예약 |
| **시간 단위 예약** | 10 / 15 / 30분 / 1시간 단위 선택 가능. 시작·종료 시간 지정 |
| **중복 방지** | 같은 회의실·같은 시간은 **서버에서** 거절. 두 부서가 동시에 눌러도 한 건만 저장 |
| **예약자 표시** | 부서 · 이름 · 회의 제목 · 참석 인원 · 메모 |
| **본인 취소** | 예약할 때 정한 4자리 비밀번호로 직접 취소 (관리자 비밀번호로도 가능) |
| **현재 상태** | 상단에 «지금 사용 중 / 비어 있음 · 다음 예약» 실시간 표시 |
| **QR 생성·인쇄** | 앱 안에서 QR 이미지를 만들고, 회의실 문에 붙일 안내문을 바로 인쇄 |
| **관리자 설정** | 회의실 이름·정원·색, 부서 목록, 운영시간, 예약 단위, 최대 이용시간, 주말 허용 여부 |
| **휴대폰 앱 설치** | PWA — 홈 화면에 추가하면 주소창 없는 앱처럼 실행 |

## 3단계 설치

### 1단계 — 사이트 켜기 (GitHub Pages)

1. 이 저장소 **Settings → Pages**
2. Source = **Deploy from a branch**, Branch = `main` / `/(root)` 저장
3. 잠시 뒤 아래 주소가 살아납니다

   ```
   https://<계정명>.github.io/my_money/rooms/
   ```

이 시점에도 앱은 열리지만 **«이 기기 전용» 모드**입니다.
내 폰에서 한 예약이 다른 사람에게는 보이지 않습니다. 2단계를 꼭 하세요.

### 2단계 — 공용 저장소 연결 (⭐ 가장 중요)

모든 부서가 같은 예약 현황을 보려면 데이터를 한곳에 모아야 합니다.
아래 **둘 중 하나**만 고르면 됩니다.

<details open>
<summary><b>방법 A. Google 스프레드시트 (권장 — 무료, 카드 등록 없음)</b></summary>

1. [Google 스프레드시트](https://sheets.new)에서 새 시트를 하나 만듭니다.
   (이름 예: `회의실 예약 데이터`)
2. 메뉴 **확장 프로그램 → Apps Script** 클릭
3. 편집기에 있던 내용을 모두 지우고, 이 저장소의
   [`rooms/apps-script/Code.gs`](apps-script/Code.gs) 내용을 **전부 복사해 붙여넣기** → 저장(💾)
4. 오른쪽 위 **배포 → 새 배포**
   - 유형 선택(⚙) → **웹 앱**
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자**  ← 이걸 꼭 «모든 사용자»로
   - **배포** → 권한 승인(«고급» → «…(안전하지 않음)으로 이동» → 허용)
5. 나온 **웹 앱 URL**을 복사합니다. (`https://script.google.com/macros/s/…/exec`)
6. 이 저장소의 `rooms/index.html` 을 열어 위쪽 설정 블록을 이렇게 고칩니다.

   ```js
   var BACKEND = {
     mode: 'gas',
     url : 'https://script.google.com/macros/s/여기에_복사한_주소/exec',
     key : ''
   };
   ```

7. 저장하고 커밋 → 1~2분 뒤 사이트에 반영됩니다.

시트에 `bookings` · `config` 탭이 자동으로 생기고, 예약이 한 줄씩 쌓입니다.
관리자는 스프레드시트만 열어도 전체 예약 현황을 볼 수 있습니다.

> 웹앱 주소를 브라우저에 그냥 붙여넣었을 때
> `{"ok":true,"data":"회의실 예약 백엔드가 정상 동작 중입니다."}` 가 보이면 성공입니다.

</details>

<details>
<summary><b>방법 B. Supabase (예약이 많거나 더 빠른 응답이 필요할 때)</b></summary>

1. [supabase.com](https://supabase.com)에서 무료 프로젝트 생성
2. **SQL Editor**에 [`rooms/supabase.sql`](supabase.sql) 내용을 붙여넣고 **Run**
3. **Project Settings → API** 에서 `Project URL` 과 `anon public` 키 복사
4. `rooms/index.html` 위쪽 설정 블록 수정

   ```js
   var BACKEND = {
     mode: 'supabase',
     url : 'https://xxxxxxxxxxxx.supabase.co',
     key : 'eyJhbGciOi...(anon public 키)'
   };
   ```

Supabase 쪽은 `EXCLUDE` 제약으로 **데이터베이스가 직접** 시간 겹침을 막고,
취소 비밀번호도 서버 함수에서 검증합니다. 예약 취소용 비밀번호 해시는
익명 키로 **조회 자체가 불가능**하도록 컬럼 권한이 걸려 있습니다.

</details>

### 3단계 — QR 만들어 붙이기

1. 폰이나 PC에서 사이트를 엽니다
2. 오른쪽 위 **⚙ 설정 → QR 코드 · 안내문**
3. **QR 이미지 저장** (PNG) 또는 **안내문 인쇄** 를 누릅니다
4. 인쇄물을 각 회의실 문·게시판에 붙입니다

> QR은 브라우저 안에서 직접 만들어집니다. 외부 QR 사이트에 주소를 넘기지 않습니다.

## 처음 한 번 — 관리자 설정

⚙ 설정 → **회의실 · 운영 규칙** 에서 원하는 숫자 4자리를 입력하면
그 번호가 **관리자 비밀번호**로 등록됩니다. (한 번만; 이후에는 그 번호로 열립니다)

여기서 정하는 것들:

- 조직/앱 이름 (예: `한마음산업 회의실`)
- 회의실 목록 — 이름 · 정원 · 달력에 표시될 색 (2개든 5개든 자유롭게)
- 부서 목록 — 예약 화면 부서 선택지
- 운영 시간 (예: 08:00 ~ 20:00), 예약 단위(30분 등)
- 1회 최대 이용 시간, 며칠 뒤까지 예약 가능, 주말 허용 여부

저장하면 **QR로 접속하는 모든 사람에게 똑같이** 적용됩니다.

## 직원 사용법 (안내문에 그대로 써도 됩니다)

1. 회의실 문의 **QR을 카메라로 스캔**
2. 달력에서 **원하는 날짜를 터치**
3. 시간표에서 **비어 있는 시간대를 터치**
4. 부서 · 이름 · 회의 제목 · **취소용 비밀번호 4자리** 입력 → **예약하기**
5. 취소하려면 내 예약을 눌러 **그 비밀번호**를 입력

> 자주 쓰는 부서·이름은 ⚙ 설정 → «내 정보» 에 저장해 두면 매번 자동으로 채워집니다.

**폰에 앱으로 설치하기**
- Android(Chrome): 메뉴(⋮) → **앱 설치**
- iPhone(Safari): 공유(□↑) → **홈 화면에 추가**

## 알아두면 좋은 점

**예약 비밀번호에 대해**
사내 편의용 잠금장치입니다. 비밀번호는 원문이 아니라 해시로만 저장되고,
Supabase·Apps Script 모두 **서버에서** 대조합니다. 다만 로그인 시스템이 아니므로
«누가 예약했는지 위조»까지 막지는 못합니다. 사내 게시판 수준의 신뢰 모델로 쓰세요.

**동시 예약**
두 부서가 같은 시간을 동시에 눌러도 한 건만 저장됩니다.
(Apps Script는 `LockService`, Supabase는 `EXCLUDE` 제약이 처리합니다.)
밀린 쪽에는 «조금 전에 다른 분이 같은 시간을 예약했습니다» 안내가 뜹니다.

**최신 상태 반영**
화면을 다시 켜거나 달을 넘길 때마다 서버에서 새로 읽어옵니다.
누가 방금 예약했는지 확인하려면 화면을 껐다 켜거나 새로고침하세요.

**오프라인**
앱 화면 자체는 캐시되어 인터넷이 끊겨도 열리지만, 예약 조회·저장은 인터넷이 필요합니다.
예약 데이터는 캐시하지 않습니다(항상 최신을 봐야 하므로).

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 앱 전체 (화면 + 로직 + QR 생성기). **BACKEND 설정도 이 파일 위쪽** |
| `manifest.webmanifest` | 앱 이름 · 아이콘 (PWA) |
| `sw.js` | 서비스 워커 — 앱 껍데기만 캐시 |
| `icons/` | 홈 화면 아이콘 |
| `apps-script/Code.gs` | Google 스프레드시트 백엔드 (방법 A) |
| `supabase.sql` | Supabase 스키마 · 권한 · 함수 (방법 B) |

## 문제 해결

| 증상 | 확인할 것 |
|---|---|
| «이 기기 전용» 노란 배너가 보임 | `index.html` 의 `BACKEND.mode` 가 아직 `'local'` 입니다 → 2단계 참고 |
| «공용 저장소에 연결하지 못했습니다» | Apps Script 배포 시 액세스 권한이 **모든 사용자**인지, 웹앱 URL이 `/exec` 로 끝나는지 확인 |
| 코드를 고쳤는데 반영이 안 됨 | Apps Script는 수정 후 **배포 → 배포 관리 → 편집(✏) → 버전: 새 버전 → 배포** 를 해야 반영됩니다 |
| 관리자 비밀번호를 잊음 | (A) 스프레드시트 `config` 탭에서 `main` 행 삭제 (B) Supabase에서 `delete from app_config;` — 설정이 초기화되고 다시 정할 수 있습니다 |
| 예약이 두 번 들어감 | 새로고침해 보세요. 서버가 중복을 막으므로 실제로는 한 건만 저장됩니다 |
